# 独立歌曲的临时歌手续播队列

关联 [songloft-org/songloft-plugin-miot#130](https://github.com/songloft-org/songloft-plugin-miot/issues/130#issuecomment-6393443720)。[English](en/issue-130.md)。

## 行为

- 点播不属于任何歌单的歌曲时，先播放匹配歌曲，再续播曲库中同歌手的其他歌曲。新搜索并入库的歌曲、开启「不入库直接播放」的直链歌曲也复用此路径；已配置目标歌单且接管成功时，仍播放目标歌单。
- 队列显示为「歌手: 名称」，沿用临时歌单接口与现有前端列表，可选曲、上一首、下一首。缺少歌手信息或同歌手歌曲时，仅播放匹配歌曲；电台不扩展歌手队列。
- 同歌手候选来自当前歌曲索引（受 `max_song_index` 限制），包含未加入歌单的记录。按归一化后的完整歌手字段匹配，兼容简繁与大小写，按歌曲 ID 去重；不使用语音搜索的模糊歌手匹配，不主动从网上抓取歌手曲目列表。
- 读取完整歌曲详情最多并发四次，保留 URL、类型与时长。单条删除/读取失败不阻断点播；停止、新点歌、语音任务取消或外部接管后，迟到的结果不能替换队列。
- 使用设备设置的播放模式：顺序、随机、列表循环继续操作同一队列；单曲循环重复当前歌曲，单曲播放在当前歌曲结束后暂停。
- 已入库队列保存歌手来源、初始点播歌曲 ID 和当前歌曲 ID。重载后重建队列并恢复选择，不自动向音箱推流；网页在同一列表内选曲时保留来源。未入库的临时直链不保存恢复标记，避免重载后重放过期链接。所有临时队列清理旧实体歌单与重载续播锚点。
- 源歌曲没有有效时长时仍由已有设备进度探测判断结束，不凭空设定播完时间。

## 原因与验证
